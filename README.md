# ⚡ SOLVIX | Atlas Eléctrico de México

Proyecto académico de TE1020 — Análisis de Circuitos Eléctricos.

Atlas interactivo para explorar los recursos energéticos, la generación, transmisión y distribución de electricidad en México.

Incluye mapas interactivos, gráficas, simuladores y datos de fuentes oficiales como CFE, SENER y CENACE.
